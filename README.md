# M/S Distribution - Android APK (GitHub Actions)
1. Is poore folder ki files apni GitHub repo mein upload karein (.github folder samet).
2. Repo > Actions tab > "Build Android APK" khud chalega (ya Run workflow dabayein). 5-8 minute lagte hain.
3. Repo > Releases mein "MS Distribution APK" milega. MS-Distribution.apk download karke install karein.
